# LVGL Мастерская

Онлайн-редактор интерфейсов LVGL: визуальный дизайнер + генерация `ui.c` / `ui.h` + редактор `app.c` (CodeMirror 6).

Локально: `npm install && npm run dev`

GitHub Pages: залей проект в репозиторий (ветка `main`), затем Settings → Pages → Source: **GitHub Actions**.
Сайт соберётся и опубликуется автоматически (`.github/workflows/deploy.yml`).
